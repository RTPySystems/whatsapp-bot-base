# Segurança

Encontrou uma vulnerabilidade? Não publique tokens, arquivos de sessão ou dados de usuários
em issues. Use o canal de contato disponível em [rtcloud.com.br](https://rtcloud.com.br)
para combinar um relato privado com RTPySystems.

Inclua uma reprodução com dados fictícios, impacto e versões envolvidas. Se uma credencial
vazou, revogue-a na plataforma de origem imediatamente; apagar o commit não basta.

Esta base não inclui auditoria de segurança independente nem SLA. Antes de usar em produção,
revise permissões, dependências, limites de uso, armazenamento e as políticas da plataforma.
